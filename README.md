# Personal Web Portfolio - Pattapon Sritaveesinsup

เว็บไซต์ส่วนตัวแบบสแตติก (Static Website) ที่พัฒนาขึ้นเพื่อรวบรวมประวัติการศึกษา ทักษะทางเทคนิค ผลงานที่ผ่านมา และการมีส่วนร่วมในกิจกรรมต่าง ๆ

## 🗂 โครงสร้างไฟล์ในโปรเจกต์ (File Structure)
เว็บไซต์นี้ประกอบด้วยไฟล์ HTML หลักดังนี้:
- `Home.html` : หน้าแรก (Entry Point) ที่แสดงภาพรวมและสรุปข้อมูลเบื้องต้น[cite: 10, 12]
- `About-Me.html` : หน้าแนะนำตัว ประวัติการศึกษา และสิ่งที่สนใจ[cite: 7, 12]
- `Projects.html` : แสดงรายละเอียดโปรเจกต์ที่พัฒนา เช่น ระบบ Security Patrol Roster และระบบสืบค้นข้อมูลโรงแรมเบย์วิว[cite: 11, 12]
- `Technical-Skills.html` : สรุปทักษะทางเทคนิค เครื่องมือ และเทคโนโลยีที่ใช้งาน[cite: 10, 12]
- `Activities.html` : บันทึกกิจกรรมที่เข้าร่วม เช่น งาน BU Cyber Fortress Challenge & Career Expo[cite: 8, 12]
- `Certifications.html` : รวมใบรับรองและประกาศนียบัตร เช่น Cybersecurity Foundation Course[cite: 9, 12]

## 🛠 เทคโนโลยีที่ใช้ (Technologies Used)
- **โครงสร้างและการจัดการ Layout:** HTML5, CSS3, Bootstrap 5.3
- **ไอคอน:** Bootstrap Icons
